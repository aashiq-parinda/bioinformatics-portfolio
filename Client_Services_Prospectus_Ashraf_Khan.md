## 🔬 Service Catalog Breakdown

### 1. Transcriptomics & Spatial Multi-Omics
- **Bulk RNA-Seq:** Complete processing from FASTQ / count matrices $\to$ library size normalization (DESeq2 median-of-ratios) $\to$ negative binomial GLM differential expression $\to$ Wald test with Benjamini-Hochberg FDR control $\to$ Volcano, MA, and PCA plots $\to$ Over-Representation Analysis (GO Biological Process, Molecular Function, KEGG pathways).
- **Single-Cell RNA-Seq (scRNA-seq):** 10x Chromium processing $\to$ doublet identification (`Scrublet`) $\to$ mitochondrial/ribosomal filtering $\to$ batch integration (`Harmony` or deep generative `scVI`) $\to$ Leiden graph clustering $\to$ automated marker gene identification and publication-quality UMAP figures.
- **Spatial Transcriptomics (10x Visium):** Histology spot alignment $\to$ Moran's $I$ spatially variable genes $\to$ reference-based Bayesian cell-type deconvolution (`Cell2location`) mapping exact immune/stromal subsets onto tumor tissue $\to$ paracrine ligand-receptor communication modeling.

### 2. Generative AI & Protein Engineering
- **ESM-2 In-Silico Deep Mutational Scanning:** Comprehensive $19 \times L$ amino-acid substitution fitness prediction using Meta's Evolutionary Scale Model (`ESM-2`) masked marginal log-likelihood ratios. Tested against experimental MaveDB benchmarks to isolate functional hotspots, stabilizing mutations, or drug-resistance escape variants.
- **AlphaFold Structural Confidence Assessment:** Extraction of per-residue pLDDT confidence curves, Predicted Aligned Error (PAE) inter-domain matrices, secondary structure distribution, and binding cleft mapping.
- **Bespoke 3D Biotech Web Applications:** Building interactive web dashboards (`Streamlit`, `FastAPI`, `py3Dmol`/`Mol*`) deployed on cloud infrastructure (AWS/GCP), allowing non-computational biologists to upload sequences, inspect 3D models, and query predictions.

### 3. Computational Drug Discovery & Biophysics
- **Virtual Screening & Docking:** Target receptor preparation $\to$ ligand 3D conformer optimization and protonation (`RDKit`) $\to$ parameterized `AutoDock Vina` screening $\to$ binding pose clustering and non-covalent interaction profiling (`PLIP` H-bonds, salt bridges, $\pi$-stacking).
- **All-Atom Molecular Dynamics (OpenMM):** Explicit TIP3P solvent box setup with physiological ions (0.15 M NaCl) $\to$ small-molecule parameterization (`OpenFF 2.1` / `GAFF2`) $\to$ 4-stage GPU simulation protocol (Minimization, NVT heating, NPT equilibration, 20–100 ns production) $\to$ `MDAnalysis` trajectory evaluation (RMSD, RMSF, hydrogen bond kinetics) $\to$ thermodynamic binding free energy calculation via **MM-PBSA**.

### 4. Production Engineering & Cloud Genomics
- **Nextflow DSL2 Workflows:** Enterprise-grade pipeline development following **nf-core** standards. Modular architecture with isolated process containers (`Docker`/`Singularity`), automated resource retry handlers, support for AWS Batch, Slurm, and GCP Life Sciences, and automated `MultiQC` synthesis reports.
- **Custom Bioinformatics Python Packages:** Development of standalone, pip/conda-installable CLI tools using `Typer` and `Rich`, complete with unit tests (`pytest`), typed APIs, and Sphinx/Markdown documentation.

### 5. Clinical Genomics & Precision Oncology
- **Somatic Variant Interpretation Engine:** Ingesting tumor-normal VCFs $\to$ functional consequence annotation (`Ensembl VEP`) $\to$ population allele filtering (`gnomAD`) $\to$ programmatic querying of clinical oncology knowledgebases (`CIViC API`, `ClinVar`) $\to$ automated classification into **AMP/ASCO/CAP Tiers I–IV** (FDA-approved therapies down to benign polymorphisms) $\to$ automated generation of oncologist-ready molecular pathology PDF reports.
